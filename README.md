# SEO Rank Tracker

A full-stack application for website SEO audits and Google keyword rank tracking.

## Features

- Website SEO audits
- Google keyword rank tracking
- AI-powered SEO scoring and recommendations
- JWT-based authentication
- SEO analysis and ranking history
- Automated daily rank updates

## Tech Stack

- React
- TypeScript
- Node.js
- Express.js
- MongoDB
- Gemini AI
- Playwright
- Browserbase
- JWT
- Node-Cron

## Project Overview

The application combines automated website analysis, keyword tracking, and AI-powered recommendations to help users monitor and improve SEO performance.
